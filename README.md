# 拾光集市 · 前端购物页面

一个零依赖的静态购物页面（纯 HTML/CSS/JS），无需构建，直接用浏览器打开 `index.html` 即可。

## 本地预览

```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

也可以直接双击 `index.html`。

## 功能

- 顶栏：搜索框（按名称/分类实时过滤）、购物车入口（数量角标）
- Hero 区域：主标题、卖点、立即选购与领券入口
- 分类筛选：全部 / 家居 / 数码 / 穿搭 / 食品
- 商品网格：每行自适应列数，移动端双列
- 收藏：心形按铃切换，状态本地持久化
- 购物车抽屉：增减数量、删除单行、实时合计
- 满 ¥199 免邮提示：提示还差多少，达标后显示包邮
- 结算：点击“去结算”弹出 Toast 并清空购物车（演示逻辑）
- 响应式：980 / 720px 两个断点，支持无障碍键盘操作与 reduced-motion

## 文件结构

```
index.html   页面结构
styles.css   样式与响应式
app.js       商品数据与全部交互逻辑
```

商品数据集中在 `app.js` 顶部的 `PRODUCTS` 数组，改数据不需要动布局。
